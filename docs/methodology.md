# 评测方法学与推广声明（草案）

## 1. 评测原则

- 结论优先，但必须可解释：结论后紧跟“依据是什么”。
- 以任务为单位评测：写功能、改 Bug、补测试、PR Review、Repo Chat 等。
- 强调边界与局限：明确“不适合谁/不适合场景”。

## 2. 信息来源与可追溯

- 价格/购买入口：优先引用官方入口或官方授权渠道，并标注 `updatedAt`。
- 隐私/合规：优先引用官方政策与企业条款；无法确认时必须标注不确定性。

## 3. 推广声明

- 任何包含推广链接的页面必须展示 `affiliateDisclosure`。
- 推广不影响结论：推荐依据必须落在可复核的能力/场景/成本分析上。
