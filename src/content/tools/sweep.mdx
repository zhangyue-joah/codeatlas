## 适合用 Sweep 的一个判断

如果你的痛点是“GitHub issue 很多但都是小修小补”，并且你愿意用 PR 审查来兜底，Issue→PR 形态的 Agent 往往更容易落地。

## 使用建议（团队落地）

- 先把权限与触发条件收紧：只允许特定仓库/目录/标签触发
- 所有产出必须走 PR Review，并对关键目录启用额外检查（测试/CI/保护分支）
