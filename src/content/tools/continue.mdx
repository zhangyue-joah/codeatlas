## 适合用 Continue 的一个判断

如果你想要“开源 + 可控模型渠道”，并且愿意自己把提示词、模型与团队约束配置好，Continue 更适合作为长期可控的 VS Code 方案。

## 使用建议

- 先把模型渠道与限额跑通：主渠道优先官方/云平台，准备备选渠道
- 让回答引用证据：要求指明文件/符号/调用链，再给改动建议
