## 建议的“计划输出格式”

让 Agent 按下面结构输出计划（你确认后再写入）：

1. **改动文件清单**（逐个说明原因）
2. **风险点**（兼容性/影响面/回滚）
3. **验证命令**（最小可行：lint/test/build 其一）
4. **分步执行顺序**（每一步的检查点）
