## GPT Engineer 是什么

GPT Engineer 是一个开源工具，可以从自然语言需求描述生成完整的项目代码。它的核心理念是：

- **需求驱动**：用自然语言描述你想要什么
- **完整项目**：生成可运行的项目，不只是代码片段
- **交互式**：生成过程中可以回答 AI 的澄清问题

## 适用场景

- **快速原型**：验证想法，快速生成 MVP
- **学习参考**：看 AI 如何组织项目结构
- **项目骨架**：生成基础代码，再手动完善

## 不适用场景

- 复杂业务逻辑（需要大量领域知识）
- 对现有项目的修改（更适合从零开始）
- 生产级代码（需要大量人工审查和优化）

## 与其他工具对比

| 工具 | 定位 | 特点 |
|------|------|------|
| GPT Engineer | 项目生成 | 开源、CLI、从零生成 |
| Lovable | Web 应用生成 | 在线、可视化、托管部署 |
| Bolt.new | 全栈应用 | 在线、实时预览、一键部署 |
| v0 | UI 组件 | Vercel 出品、专注前端 |

## 需求描述技巧

好的需求描述应该包含：

1. **功能点**：具体要实现什么功能
2. **技术栈**：使用什么语言/框架
3. **约束条件**：有什么限制或要求
4. **UI 风格**：界面的大致风格

```
# 好的需求描述示例
创建一个博客系统：
- 技术栈：Next.js + TypeScript + Tailwind CSS
- 功能：文章列表、文章详情、Markdown 渲染
- 数据：使用本地 JSON 文件作为数据源
- UI：简洁现代，支持暗色模式
```
