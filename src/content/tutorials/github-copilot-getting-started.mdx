## 推荐的提示词骨架（直接替换方括号）

> 我要在这个 repo 里实现：\[一句话需求]  
> 验收标准：  
> 1) \[可验证标准 1]  
> 2) \[可验证标准 2]  
> 3) \[可验证标准 3]  
> 约束：只改 \[文件/目录]；不改 \[明确不改的内容]；先给“文件清单 + 改动点 + 风险”，我确认后再写代码。  

## 什么时候要升级到 Agent？

如果你的任务经常是“改完代码还要补测试、跑命令、修报错、再提 PR”，建议在 Copilot 之上加一个 Agent 工具（如 Cursor / VS Code Agent / CLI Agent），把多步闭环做得更稳。
