## Augment Code 是什么

Augment Code 是一款面向团队和企业的 AI 编程助手，核心优势是**大型代码库的上下文理解**。它可以：

- 理解整个代码库的结构和依赖关系
- 提供基于全局上下文的代码补全
- 回答跨文件、跨模块的代码问题
- 帮助快速定位和理解代码

## 适用场景

- **大型项目**：多模块、大仓库的代码理解
- **团队协作**：快速理解他人代码
- **代码导航**：定位函数调用、依赖关系
- **知识沉淀**：代码库级别的问答
