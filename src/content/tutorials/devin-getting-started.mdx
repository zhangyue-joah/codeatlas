## Devin 是什么

Devin 是 Cognition Labs 推出的"AI 软件工程师"，它可以：

- **端到端执行任务**：从需求理解到代码交付
- **自主规划和执行**：自动拆解任务、编写代码、调试问题
- **使用完整开发环境**：代码编辑器、终端、浏览器一应俱全
- **实时可观察**：你可以看到它的每一步操作

## Devin vs 其他 AI 编程工具

| 维度 | Devin | Cursor/Copilot | Claude Code |
|------|-------|----------------|-------------|
| 定位 | AI 软件工程师 | AI 编程助手 | CLI Agent |
| 自主性 | 高（端到端） | 低（辅助为主） | 中（交互式） |
| 人工介入 | 可选 | 必须 | 推荐 |
| 适合任务 | 完整功能/修复 | 代码片段/补全 | 多步任务 |
| 价格 | 较高 | 中等 | 按量付费 |

## 适用场景

- **Bug 修复**：给出 Issue 描述，让 Devin 定位并修复
- **功能开发**：描述需求，让 Devin 实现完整功能
- **代码迁移**：批量更新代码风格或框架版本
- **文档生成**：根据代码生成文档

## 不适用场景

- **核心业务逻辑**：需要深度领域知识的复杂决策
- **架构设计**：需要全局视角和权衡的设计工作
- **安全敏感代码**：涉及认证、加密等关键代码
- **紧急修复**：需要快速响应的生产问题

## 任务描述技巧

好的任务描述应该包含：

1. **背景**：为什么要做这个任务
2. **目标**：具体要实现什么
3. **约束**：有什么限制或要求
4. **验收标准**：怎么判断任务完成

```
# 好的任务描述示例
背景：用户反馈登录页面在移动端显示异常
目标：修复登录页面的移动端适配问题
约束：
- 只修改 src/pages/Login 相关文件
- 保持桌面端样式不变
- 使用现有的 Tailwind CSS 类
验收标准：
- 在 375px 宽度下正常显示
- 表单元素可正常交互
- 通过现有的 E2E 测试
```

## 审查清单

Devin 交付的代码，务必检查：

- [ ] 功能是否符合需求
- [ ] 代码风格是否符合规范
- [ ] 是否引入安全漏洞
- [ ] 测试是否通过
- [ ] 是否有不必要的改动
