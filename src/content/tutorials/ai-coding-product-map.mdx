## 一句话选型：你需要哪一类产品？

- **只想提升日常编码速度（低风险）**：IDE 插件/补全（如 GitHub Copilot、Codeium、Tabnine、JetBrains AI Assistant、Amazon Q、Gemini Code Assist）
- **想把“多步任务”跑到可提交（中风险）**：Agentic IDE / VS Code Agent / CLI Agent（如 Cursor、Windsurf、Cline、Continue、Aider、Claude Code、OpenAI Codex CLI）
- **想“从想法到应用”快速搭原型（高变更）**：App Builder（如 Bolt.new、v0、Lovable、Replit Agent）
- **想把质量关卡“自动化”（团队落地）**：PR Review / 测试 / 安全工具（如 CodeRabbit、Snyk/CodeQL 相关、各类 PR Review Bot）

## 常见 AI 编程产品清单（按形态）

下表是“常见且经常被用来做开发”的产品/项目清单，用于快速定位（不代表推荐顺序）。

| 形态 | 常见产品（示例） | 适合人群/任务 |
| --- | --- | --- |
| Agentic IDE | Cursor、Windsurf、Trae（不同地区可能有差异） | 需要“多步闭环”：写功能/重构/补测试 |
| IDE 插件 | GitHub Copilot、JetBrains AI Assistant、Amazon Q Developer、Gemini Code Assist、Codeium、Tabnine | 不想换编辑器，追求低接入成本 |
| VS Code Agent | Cline、Continue、Roo Code、各种 Chat/Agent 扩展 | 想在 VS Code 内实现“计划→改动→验证” |
| CLI Agent | Aider、Claude Code、OpenAI Codex CLI、SWE-agent、OpenHands | 偏终端工作流、可控脚本化、可集成 CI |
| 代码搜索/理解 | Sourcegraph Cody、（各家 IDE 内置的 repo chat） | 大仓库理解、定位调用链、答疑 |
| App Builder | Bolt.new、v0、Lovable、Replit Agent | 快速做 Demo/原型，接受大幅自动生成 |
| 自托管助手 | Tabby、Ollama + 各类编辑器插件、vLLM | 内网/合规要求强、希望本地推理或自控部署 |

## 组合建议（常用“1+1”）

- **插件补全 + Chat/Agent**：Copilot/Codeium + Cline/Continue（低门槛，循序渐进）
- **Agentic IDE 单核**：Cursor/Windsurf（更顺滑，但要明确权限边界）
- **CLI Agent + CI**：Aider/Claude Code + 预提交钩子/CI（更可控、可审计）
