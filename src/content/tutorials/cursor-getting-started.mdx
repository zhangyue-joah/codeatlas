## 🎯 目标

跑通一次“从需求到可提交改动”的最小工作流。

## 🛠 SOP 步骤

1. 写清楚验收标准（什么算完成）
2. 让工具先输出改动计划（文件列表 + 关键点）
3. 小步实现：先最小功能，再补测试
4. 运行验证：`npm run lint` 或 `npm run build`

## ✅ 验收标准

以本页 frontmatter 的 `acceptanceCriteria` 为准。
