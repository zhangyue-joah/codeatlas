## OpenHands 是什么

OpenHands（原 OpenDevin）是一个开源的软件工程 Agent 框架，特点：

- **完全开源**：可以自由部署和定制
- **Web 界面**：提供可视化的任务管理界面
- **隔离执行**：Agent 在 Docker 容器中执行，相对安全
- **可扩展**：支持自定义工具和执行环境

## 与 SWE-agent 对比

| 维度 | OpenHands | SWE-agent |
|------|-----------|-----------|
| 界面 | Web UI | CLI |
| 部署 | Docker Compose | Python |
| 定位 | 通用 Agent | 研究/基准 |
| 易用性 | 较高 | 中等 |

## 适用场景

- **研究探索**：学习 Agent 工作原理
- **团队定制**：基于开源框架构建内部工具
- **自动化任务**：批量处理简单的代码任务

## 安全注意事项

OpenHands 的 Agent 具有执行能力，务必注意：

1. **隔离运行**：始终在 Docker 中运行
2. **权限控制**：不要给 Agent 访问敏感资源的权限
3. **人工审查**：所有改动必须人工审查后再合并
4. **成本控制**：Agent 执行消耗 Token 较多
