## Gemini CLI 是什么

Gemini CLI 是 Google 开源的命令行 AI 助手，让你可以在终端中直接与 Gemini 模型对话。它适合：

- 喜欢终端工作流的开发者
- 想要免费体验 Gemini 模型的用户
- 需要快速问答和代码辅助的场景

## 与 Claude Code 对比

| 维度 | Gemini CLI | Claude Code |
|------|------------|-------------|
| 模型 | Gemini | Claude |
| 价格 | 免费额度较多 | 按量付费 |
| Agent 能力 | 基础 | 较强 |
| 文件操作 | 只读为主 | 读写执行 |

如果你只需要简单的问答和代码解释，Gemini CLI 的免费额度很有吸引力。如果需要更强的 Agent 能力，可以考虑 Claude Code。

## 使用场景

- **代码解释**：快速理解一段代码的作用
- **代码生成**：生成简单的代码片段
- **问题排查**：分析错误信息，给出修复建议
- **学习辅助**：解释技术概念和最佳实践
