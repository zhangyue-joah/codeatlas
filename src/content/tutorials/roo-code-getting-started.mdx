## Roo Code 是什么

Roo Code 是 Cline 的社区分支，是一个开源的 VS Code Agent 插件。它可以：

- 理解整个代码库的上下文
- 自动规划和执行多步任务
- 读写文件、执行命令
- 支持多种模型提供商

## Roo Code vs Cline

| 维度 | Roo Code | Cline |
|------|----------|-------|
| 开源 | ✅ 完全开源 | ✅ 开源 |
| 更新 | 社区驱动 | 官方维护 |
| 定制 | 更灵活 | 相对标准 |
| 文档 | 社区贡献 | 官方文档 |

如果你需要深度定制或想参与社区开发，Roo Code 是不错的选择。

## 模型选择建议

| 场景 | 推荐模型 | 理由 |
|------|----------|------|
| 复杂 Agent 任务 | Claude Sonnet | 指令遵循能力强 |
| 日常编码 | GPT-4o-mini | 成本低、速度快 |
| 本地部署 | DeepSeek Coder | 开源、可私有化 |
