## 推荐的落地顺序（别反过来）

很多“接不通/不稳定”的问题，本质是把四件事搅在一起了：

1. 渠道是否可用（网络/鉴权）
2. 模型是否存在（模型 ID）
3. 工具怎么读配置（环境变量/配置文件）
4. 预算与风险（限额/审计/轮换）

所以建议顺序固定为：**先验通渠道 → 再接一个工具 → 再复制到其他工具 → 最后做团队护栏**。

## 一个“定位问题”的提问方式

当你遇到 401/404/超时等问题，把下面这段贴给 AI（别贴 key）：

1. 我使用的渠道类型：官方/云平台/授权聚合/自建网关（选一个）
2. baseUrl 形式：`https://…/v1`（是否包含 /v1）
3. 失败请求与响应（脱敏后的 curl 日志）
4. 我当前要接入的工具是：Cursor/Continue/Cline/Aider（选一个）
5. 请你把问题归类为：鉴权/路径/模型名/网络，并给出最小修复步骤
