## GitHub Copilot CLI 是什么

GitHub Copilot CLI 是 GitHub Copilot 的终端扩展，让你可以：

- **生成命令**：用自然语言描述，AI 生成对应的 shell/git/gh 命令
- **解释命令**：让 AI 解释复杂命令的含义
- **安全执行**：生成的命令需要确认后才会执行

## 核心命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `gh copilot suggest` | 生成命令 | `gh copilot suggest "压缩这个目录"` |
| `gh copilot explain` | 解释命令 | `gh copilot explain "tar -czvf"` |

## 命令类型

使用 `-t` 参数指定命令类型：

- `shell`：通用 shell 命令（默认）
- `git`：Git 相关命令
- `gh`：GitHub CLI 命令

```bash
# 生成 git 命令
gh copilot suggest -t git "合并 feature 分支到 main"

# 生成 gh 命令
gh copilot suggest -t gh "创建一个 issue"
```

## 设置别名

为了更方便使用，可以设置别名：

```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
alias '??'='gh copilot suggest'
alias '?!'='gh copilot explain'

# 使用
?? "查找所有 TODO 注释"
?! "grep -rn TODO ."
```
