## PR-Agent 是什么

PR-Agent 是 Qodo（原 Codium AI）开源的 PR 自动化工具。它可以：

- **自动审查代码**：识别潜在问题、安全风险、代码异味
- **生成 PR 描述**：自动总结改动内容和影响
- **提供改进建议**：基于最佳实践给出优化建议
- **回答问题**：针对 PR 内容进行问答

## 核心命令

| 命令 | 功能 | 使用场景 |
|------|------|----------|
| `/review` | 代码审查 | 每个 PR 必用 |
| `/describe` | 生成描述 | PR 创建时 |
| `/improve` | 改进建议 | 代码优化 |
| `/ask` | 问答 | 理解改动 |
| `/update_changelog` | 更新日志 | 版本发布 |

## 与 CodeRabbit 对比

| 维度 | PR-Agent | CodeRabbit |
|------|----------|------------|
| 开源 | ✅ 完全开源 | 部分开源 |
| 自托管 | ✅ 支持 | 需企业版 |
| 价格 | 免费/Pro | 免费/付费 |
| 功能 | 聚焦 PR | 更全面 |

如果你需要完全控制或自托管，PR-Agent 是更好的选择。

## 团队落地建议

1. **试点阶段**：先在 1-2 个项目试用
2. **配置调优**：根据团队规范调整审查规则
3. **渐进推广**：从建议模式开始，逐步增加自动化
4. **持续优化**：收集反馈，迭代配置
