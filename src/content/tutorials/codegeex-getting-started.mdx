steps:
  - step: 1
    title: 安装插件并登录
    description: 在 IDE 插件市场安装 CodeGeeX，按提示完成登录/授权。
    tips:
      - 官网：https://codegeex.cn/
  - step: 2
    title: 打开仓库并等待索引
    description: 打开一个真实项目，确保 AI 能读取到关键文件与目录结构。
    tips:
      - 大仓库建议先从“单模块/单目录”开始
  - step: 3
    title: 跑通一次代码补全
    description: 在一个函数里输入几行，让 AI 生成补全建议并体验接受/撤销。
    code: |
      // 示例：输入函数签名，观察补全建议
      function formatPrice(amount: number) {
        // ...
      }
  - step: 4
    title: 先解释，再改动
    description: 选中一段你不确定的代码，让 AI 先解释行为与边界条件。
    tips:
      - “请用 3-5 条要点解释这段逻辑，并列出可能的边界条件”
  - step: 5
    title: 输出最小改动建议并落地
    description: 让 AI 给“改哪些文件/怎么改/风险点/验证命令”，你确认后手动修改并跑最小验证。
    warnings:
      - 不要让 AI 直接重写整个文件；先要变更摘要与文件清单
keyTips:
  - 先拿到“解释 + 文件清单”，再进入改动阶段
  - 把一次改动控制在 1-3 个文件内，尽量小步提交
  - 任何建议最终以测试/构建结果作为准入
safety:
  checklist:
    - 敏感代码与密钥不要直接发给工具
    - AI 生成的代码仍需人工审查与最小验证
    - 变更范围不清时先要求给计划与文件清单
  updatedAt: "2026-01-11"
commonFailures:
  - problem: AI 给出的建议不贴近仓库
    solution: 明确引用文件/函数名；让它先输出调用链/入口位置
  - problem: 补全不触发
    solution: 检查插件状态与网络；尝试重启 IDE
  - problem: 改动落地后验证失败
    solution: 把失败日志贴回去，让 AI 先解释原因再给最小修复
