## 为什么选 CodeGPT

CodeGPT 的核心优势是**多模型统一接入**：你可以在同一个扩展里切换 OpenAI、Claude、Gemini 等不同模型，不用为每个模型装一个插件。

适合以下场景：
- 想在 VS Code 里快速体验多种 AI 模型
- 团队需要统一的 AI 编程入口，但模型选择灵活
- 已有 API Key，想直接接入而非使用特定厂商的官方插件

## 配置要点

### 模型选择建议

| 场景 | 推荐模型 | 理由 |
|------|----------|------|
| 日常补全 | GPT-4o-mini / Claude Haiku | 响应快、成本低 |
| 复杂问答 | GPT-4o / Claude Sonnet | 理解能力更强 |
| 代码生成 | Claude Sonnet / GPT-4o | 代码质量较高 |

### 成本控制

- 补全场景建议用小模型，问答场景再用大模型
- 关注 Token 消耗，避免大文件整体发送
- 团队场景建议设置用量上限或使用企业账户
