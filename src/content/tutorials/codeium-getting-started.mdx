## Codeium 是什么

Codeium 是一款免费的 AI 代码补全工具，核心特点：

- **完全免费**：个人版功能完整，无需付费
- **广泛兼容**：支持 40+ IDE 和编辑器
- **功能全面**：补全 + Chat + 搜索
- **稳定可靠**：补全质量稳定，适合日常使用

## 为什么选 Codeium

| 对比项 | Codeium | GitHub Copilot |
|--------|---------|----------------|
| 价格 | 免费 | $10/月 |
| IDE 支持 | 40+ | 主流 IDE |
| 补全质量 | 良好 | 优秀 |
| Chat 功能 | ✅ | ✅ |
| 企业版 | 有 | 有 |

如果你想要免费的 AI 代码补全，Codeium 是最佳选择。

## 核心功能

- **代码补全**：实时智能补全，支持多行
- **Codeium Chat**：代码问答和生成
- **代码搜索**：在代码库中搜索
- **文档生成**：自动生成代码文档

## 使用技巧

1. **接受部分补全**：按 Ctrl+→ 逐词接受
2. **触发补全**：按 Alt+\ 手动触发
3. **切换建议**：按 Alt+] 或 Alt+[ 切换不同建议
