## 测试框架模板

### Jest (JavaScript/TypeScript)
```javascript
describe('functionName', () => {
  it('should return expected result for normal input', () => {
    // Arrange
    const input = ...;
    // Act
    const result = functionName(input);
    // Assert
    expect(result).toBe(expected);
  });

  it('should throw error for invalid input', () => {
    expect(() => functionName(invalidInput)).toThrow('Error message');
  });
});
```

### Pytest (Python)
```python
import pytest

def test_function_normal_case():
    # Arrange
    input_data = ...
    # Act
    result = function_name(input_data)
    # Assert
    assert result == expected

def test_function_raises_error():
    with pytest.raises(ValueError):
        function_name(invalid_input)
```

### JUnit (Java)
```java
@Test
void shouldReturnExpectedResult() {
    // Arrange
    var input = ...;
    // Act
    var result = functionName(input);
    // Assert
    assertEquals(expected, result);
}

@Test
void shouldThrowExceptionForInvalidInput() {
    assertThrows(IllegalArgumentException.class, () -> {
        functionName(invalidInput);
    });
}
```

## 测试类型

### 单元测试
- 测试单个函数/方法
- 隔离外部依赖
- 快速执行

### 集成测试
- 测试模块间交互
- 可能涉及数据库/API
- 验证端到端流程

### 边界测试
- 空值/null
- 空数组/空字符串
- 最大/最小值
- 特殊字符
