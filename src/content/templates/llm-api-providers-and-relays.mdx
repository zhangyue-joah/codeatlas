## 一句话看懂三类路径

1. **官方 API**：直接在官方控制台创建 key（最清晰、最可追溯）
2. **授权聚合/路由**：一个 key 统一路由到多家模型（适合多模型对比与切换）
3. **自建网关/中转**：你自己搭一个代理/网关（便于审计、限流、成本分摊；前提是用你的合法 key）

## 选型时必问的 6 件事

1. 支持哪些模型与上下文长度？是否支持你要的工具调用/结构化输出？
2. 计费口径（输入/输出 token、缓存、工具调用）与是否有透明账单？
3. 限流/并发、峰值稳定性、SLA
4. 数据保留期限、日志策略、是否支持企业合规条款
5. 是否支持按项目/团队隔离 key 与审计
6. 是否支持 OpenAI-Compatible（能直接用在 Cursor/Continue/Aider 等工具里）
