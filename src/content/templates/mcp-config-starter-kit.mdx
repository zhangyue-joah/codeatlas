template: |
  # MCP Starter Kit (GitHub + Filesystem + Claude Desktop)
  # 目标：最小权限、最小暴露面、可审计。

  ## 1) 准备环境变量（不要写进仓库）
  # macOS/Linux (example)
  export GITHUB_TOKEN="YOUR_GITHUB_TOKEN"

  ## 2) Claude Desktop: claude_desktop_config.json 示例
  # 注意：路径与命令以你的系统/官方文档为准
  {
    "mcpServers": {
      "github": {
        "command": "npx",
        "args": ["-y", "@modelcontextprotocol/server-github"],
        "env": {
          "GITHUB_TOKEN": "YOUR_GITHUB_TOKEN"
        }
      },
      "filesystem": {
        "command": "npx",
        "args": [
          "-y",
          "@modelcontextprotocol/server-filesystem",
          "/ABSOLUTE/PATH/TO/THIS/PROJECT"
        ]
      }
    }
  }

  ## 3) 最小权限确认（上线前必做）
  - GitHub：从只读权限开始；确认确有需要再逐步放开写权限。
  - Filesystem：只授权“一个项目目录”，不要授权 home/根目录。
  - 审计：确保请求可追溯（谁、何时、做了什么、改了哪些文件/资源）。
notes:

## 常见坑（避免踩）

- 把 token 写进仓库、PR、截图或聊天记录。
- Filesystem 一次性授权整个磁盘（尤其是 `~`、`/`、含凭据的目录）。
- 默认让 Agent “能写就写”：没有 review/审计时，权限越大风险越大。
