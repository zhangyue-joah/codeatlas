## Bug 分类模板

### 运行时错误
```
错误类型：运行时错误
错误信息：[具体错误信息]
堆栈跟踪：[堆栈信息]
触发条件：[什么操作触发了错误]
```

### 逻辑错误
```
错误类型：逻辑错误
输入数据：[输入]
期望输出：[期望结果]
实际输出：[实际结果]
差异说明：[哪里不对]
```

### 性能问题
```
问题类型：性能问题
症状：[卡顿/内存泄漏/CPU 高]
触发条件：[什么情况下出现]
性能指标：[响应时间/内存占用等]
```

### 并发问题
```
问题类型：并发/竞态条件
症状：[间歇性错误/数据不一致]
复现概率：[偶发/必现]
并发场景：[多线程/异步操作]
```

## 调试检查清单

- [ ] 能否稳定复现问题？
- [ ] 问题首次出现是什么时候？
- [ ] 最近有什么代码变更？
- [ ] 是否只在特定环境出现？
- [ ] 是否与特定数据相关？
- [ ] 错误日志是否完整？

## 常见 Bug 模式

1. **空值引用** - 未检查 null/undefined
2. **类型错误** - 类型不匹配或隐式转换
3. **边界错误** - 数组越界、off-by-one
4. **异步问题** - 竞态条件、回调顺序
5. **状态问题** - 状态未正确更新或同步
