## 获取 Slack Bot Token

1. 访问 [Slack API](https://api.slack.com/apps) 创建新应用
2. 选择 "From scratch"，输入应用名称和工作区
3. 在 "OAuth & Permissions" 中添加 Bot Token Scopes：
   - `channels:history` - 读取频道消息历史
   - `channels:read` - 读取频道列表
   - `chat:write` - 发送消息
   - `users:read` - 读取用户信息
4. 安装应用到工作区
5. 复制 "Bot User OAuth Token"（以 `xoxb-` 开头）

## 获取 Team ID

Team ID 可以在 Slack 工作区 URL 中找到，或通过以下方式获取：
1. 在 Slack 中点击工作区名称
2. 选择 "Settings & administration" > "Workspace settings"
3. 在 URL 中找到 Team ID（格式：`T0123456789`）

## 可用功能

配置完成后，Claude 可以：
- 列出频道和用户
- 读取频道消息历史
- 发送消息到频道
- 搜索消息

## 安全建议

- 使用专用的 Bot 账号，不要使用个人 Token
- 定期轮换 Token
- 限制 Bot 可访问的频道
- 监控 Bot 的 API 调用日志
