## 创建 Notion Integration

1. 访问 [Notion Integrations](https://www.notion.so/my-integrations)
2. 点击 "New integration"
3. 填写名称，选择关联的工作区
4. 设置 Capabilities（建议按需选择）：
   - Read content
   - Update content
   - Insert content
5. 提交后复制 "Internal Integration Token"

## 授权 Integration 访问页面

**重要**：创建 Integration 后，需要在每个要访问的页面/数据库中手动授权：

1. 打开 Notion 页面或数据库
2. 点击右上角 `···` 菜单
3. 选择 "Connections"
4. 搜索并添加你的 Integration

## 可用功能

配置完成后，Claude 可以：
- 读取页面内容
- 查询数据库
- 创建新页面
- 更新页面内容
- 搜索内容

## 安全建议

- 只授权必要的页面和数据库
- 使用只读权限，除非确实需要写入
- 定期审查 Integration 的访问权限
- 不要在公开仓库中提交 Token
