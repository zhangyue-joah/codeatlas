example: |
  # 1) 准备环境变量（示例）
  export GITHUB_TOKEN="YOUR_GITHUB_TOKEN"

  # 2) 把 mcpServers 配置粘贴到 Claude Desktop 的配置文件后重启应用
template: |
  {
    "mcpServers": {
      "github": {
        "command": "npx",
        "args": ["-y", "@modelcontextprotocol/server-github"],
        "env": {
          "GITHUB_TOKEN": "YOUR_GITHUB_TOKEN"
        }
      },
      "filesystem": {
        "command": "npx",
        "args": ["-y", "@modelcontextprotocol/server-filesystem", "/ABSOLUTE/PATH/TO/WORKSPACE"]
      }
    }
  }
notes:
  - MCP Server 具备访问外部系统的能力，务必最小权限、可审计、可回滚。
  - 示例使用 `npx` 拉取 server 包；企业环境可改为固定版本与离线镜像。
