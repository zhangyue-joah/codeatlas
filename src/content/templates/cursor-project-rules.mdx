template: |
  # Cursor Project Rules (drop into your repo)
  # 目标：让 Agent 不扩范围、遵循风格、必须验证、输出可追溯结果。

  ## Scope
  - 只实现当前需求；不做无关重构、不改无关文件。
  - 需要新增依赖/改架构时：先解释理由 + 给替代方案 + 等待确认。

  ## Code Style
  - 遵循现有项目的 lint/format/命名约定；不要引入新的风格体系。
  - TypeScript/React 项目：优先保持组件拆分与 hooks 习惯一致。

  ## Quality Gate
  - 修改后必须给出最小验证命令（lint/test/build 任选其一，优先项目已有脚本）。
  - 若你无法执行命令：明确说明“未运行”，并给出应该运行的命令与预期结果。

  ## Safety
  - 不写入任何密钥/令牌/私有 URL；使用占位符并提醒通过环境变量配置。
  - 涉及读写/执行权限时，先给风险点与回滚方案。

  ## Output
  - 先给计划：文件列表 + 关键改动点 + 风险 + 验证命令
  - 再输出变更摘要：每个文件做了什么、为什么
