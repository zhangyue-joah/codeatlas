## 推荐的最小权限（参考）

- 只做 repo chat / PR 阅读：优先只读（read-only）
- 需要创建 issue/评论/写回建议：再逐步增加权限并配合审计

具体 scope 以 GitHub 官方与团队安全要求为准。
