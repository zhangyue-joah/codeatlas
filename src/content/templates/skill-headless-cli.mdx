## 何时使用此技能

当需要以下帮助时使用此技能：
- 在 CI/CD 流水线中集成 AI 工具
- 编写自动化脚本调用 AI CLI
- 配置无头模式运行 AI 工具
- 批量处理任务

## Claude Code 高级用法

### 会话模式
```bash
# 启动交互会话
claude

# 恢复之前的会话
claude --resume
```

### 项目上下文
```bash
# 指定工作目录
claude -p "分析这个项目" --cwd /path/to/project

# 使用 CLAUDE.md 配置
# 在项目根目录创建 CLAUDE.md 文件
```

### 输出控制
```bash
# 仅输出结果
claude -p "生成代码" --print

# JSON 格式输出
claude -p "分析代码" --output-format json

# 流式输出
claude -p "解释概念" --stream
```

## CI/CD 最佳实践

### GitHub Actions 示例
```yaml
name: AI Code Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Install Claude Code
        run: npm install -g @anthropic-ai/claude-code

      - name: Run Code Review
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: |
          DIFF=$(git diff origin/${{ github.base_ref }}...HEAD)
          echo "$DIFF" | claude -p "审查以下代码变更，关注：
          1. 潜在的 bug
          2. 安全问题
          3. 性能问题
          4. 代码风格" --print > review.md

      - name: Post Review Comment
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const review = fs.readFileSync('review.md', 'utf8');
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: review
            });
```

### GitLab CI 示例
```yaml
code-review:
  stage: review
  image: node:20
  script:
    - npm install -g @anthropic-ai/claude-code
    - git diff origin/main...HEAD | claude -p "审查代码变更" --print
  variables:
    ANTHROPIC_API_KEY: $ANTHROPIC_API_KEY
  only:
    - merge_requests
```

## 安全注意事项

1. **API Key 管理**
   - 使用 CI/CD 平台的 Secrets 功能
   - 不要在代码中硬编码 API Key
   - 定期轮换 API Key

2. **输入验证**
   - 对用户输入进行清理
   - 限制输入长度
   - 避免注入攻击

3. **输出处理**
   - 验证 AI 生成的代码
   - 不要直接执行未审查的代码
   - 记录所有 AI 操作日志
