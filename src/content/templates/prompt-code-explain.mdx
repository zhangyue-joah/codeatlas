  ```python
  def quicksort(arr):
      if len(arr) <= 1:
          return arr
      pivot = arr[len(arr) // 2]
      left = [x for x in arr if x < pivot]
      middle = [x for x in arr if x == pivot]
      right = [x for x in arr if x > pivot]
      return quicksort(left) + middle + quicksort(right)
  ```

  1. 概述：用一句话说明这段代码的核心功能

## 变体模板

### 架构解释版
```
请从架构角度解释这段代码：
1. 设计模式：使用了哪些设计模式？
2. 职责划分：各模块/类的职责是什么？
3. 依赖关系：模块间如何交互？
4. 扩展性：如何扩展或修改功能？
```

### 算法解释版
```
请解释这个算法：
1. 算法名称和类型
2. 时间复杂度和空间复杂度
3. 核心思想和步骤
4. 边界情况处理
5. 与其他算法的对比
```

### 安全审查版
```
请从安全角度审查这段代码：
1. 输入验证：是否有未验证的用户输入？
2. 注入风险：SQL/命令/XSS 注入风险？
3. 认证授权：权限检查是否完整？
4. 敏感数据：是否有数据泄露风险？
```
