template: |
  # Repository Instructions for Copilot
  ## Scope
  - Keep changes minimal and relevant to the request.
  - Do not refactor unrelated code or rename files unless asked.

  ## Coding conventions
  - Follow existing lint/format rules and project patterns.
  - Prefer small, reviewable commits/patches.

  ## Testing
  - Suggest the smallest relevant verification command (lint/test/build).
  - If you did not run commands, say so explicitly.

  ## Security & privacy
  - Never output or store secrets (API keys, tokens, credentials).
  - Avoid logging sensitive data; use placeholders and env vars.

  ## Output
  - Provide a short plan (files to change + why) before writing code.

## 放到哪里

常见做法是在仓库中放置一份“仓库指令”文件（路径以官方文档为准），让 Copilot Chat 在该 repo 下默认遵循。
